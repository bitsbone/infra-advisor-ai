Assistant prose explains a result; it should not become the client's data contract. InfraAdvisor's chat artifacts carry normalized MCP evidence beside the answer so the MAUI client can render stable cards, preserve them with a conversation, and link to official sources.

The first contract, `procurement_opportunities` version `1.0`, combines SAM.gov and Grants.gov results for the Field Advisor workflow.

## Follow the artifact boundary

<FlowExplorer client:visible title="Follow one evidence artifact" flows={artifactFlows} />

Each boundary accepts only the shared contract. Raw provider JSON never becomes an accidental mobile API.

## Contract guarantees

The canonical schema and sanitized fixtures live in `contracts/chat-artifacts`. Each artifact includes:

- `kind` and `schema_version` for client dispatch;
- an `ok`, `partial`, `empty`, or `error` status;
- generation and tool-call provenance;
- bounded, presentation-safe records;
- provider counts, truncation state, and bounded partial errors;
- missing-field metadata that distinguishes unavailable data from zero.

One procurement artifact contains at most 20 results, and the agent rejects artifacts larger than 64 KiB. Clients ignore unknown kinds and versions. Additive fields can extend a minor version; breaking changes require a new major contract and mapper.

## Normalize meaning, not just names

The providers disagree on identifiers, dates, statuses, classifications, and funding fields. Each adapter converts its response into a shared opportunity model before merge and sort. A provider value stays absent when it has no honest shared meaning; the normalizer does not force it into a convenient but misleading field.

## Extract defensively

MCP libraries expose structured results in different in-process shapes. Both agents inspect only protocol-defined locations: a bare normalized object, `structuredContent`, or an artifact encoded in a top-level text content block. They rebuild the object from allowlisted fields, enforce bounds again, and reject nested lookalikes.

Validated HTTP or HTTPS source URLs are copied into the ordinary citation list after query strings and fragments are removed. Evidence cards and restored conversations therefore keep the same safe sources.

## Persist the application payload

Streaming sends the artifact as soon as the tool result is recognized; answer text continues independently. Non-streaming responses return the same optional collection. Assistant messages store artifacts in the existing conversation table's JSONB column, while user messages keep an empty collection.

Datadog logs describe the transformation but are not an application database. The provider adapter records bounded fields such as schema version, status, counts, truncation, latency, and sanitized public identifiers. It does not record API-key-bearing URLs, contact blocks, raw bodies, or unrestricted descriptions.

<Aside type="caution">
The MCP deployment explicitly disables Agent Observability payload capture and HTTP query-string tagging. Removing either control can expose provider arguments, results, or the SAM.gov API key through automatic instrumentation.
</Aside>

## Verify the learning outcome

<ObservationChecklist>

- Submit a federal procurement request from Field Advisor.
- Confirm an evidence card arrives before or alongside the final answer.
- Compare its normalized fields and link with the official source.
- Restore the conversation and confirm the card survives.
- Follow the mobile action through agent and MCP spans.
- Search the result-summary log, then verify sentinel prompts, credentials, URLs, and provider bodies are absent.

</ObservationChecklist>

Contract, provider, agent, persistence, streaming, and MAUI tests cover malformed, partial, oversized, legacy, and unknown-version cases. Use those layers as the template when adding another artifact kind.
