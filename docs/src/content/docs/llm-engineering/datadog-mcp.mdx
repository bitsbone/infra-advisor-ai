A Datadog MCP connection can let an MCP-compatible assistant inspect observability data through natural-language investigation. It is useful for interactive questions such as “find the trace behind this bad answer” or “show the logs around this tool failure.”

Keep this boundary separate from InfraAdvisor's own MCP servers. InfraAdvisor's runtime MCP clients call infrastructure-data tools. A developer's Datadog MCP connection reads operational evidence while investigating the system.

## Use it for exploration

A productive investigation still follows the same evidence order:

1. Identify a request by time, ML application, service, trace ID, or a safe attribute.
2. Retrieve the complete agent trace rather than one model span.
3. Inspect routing, retrieval, tool, and model children in sequence.
4. Follow the correlated APM trace and logs when the failure crosses services.
5. State what the evidence proves and what remains an inference.

The MCP server's available tools and names can change. Discover the tools exposed by the connected server at investigation time instead of embedding a fixed catalog in this course.

## Choose another Datadog surface when appropriate

| Goal | Better fit |
|---|---|
| Explore one unfamiliar failure | MCP-assisted investigation |
| Repeat a known query visually | Saved view or dashboard |
| Detect a condition continuously | Monitor or automation rule |
| Retrieve many pages reliably | Export API job |
| Change production configuration | Reviewed, least-privilege workflow |

## Access safely

Use a dedicated identity with the smallest read permissions needed for the investigation. Do not reuse agent-service credentials, paste keys into prompts, or grant write access for a read-only workflow. Remember that an assistant can expose any data its connected identity can read.

This repository cannot verify a developer's local MCP client or Datadog account configuration. Treat connection instructions from the current Datadog product experience as authoritative and keep this page focused on the investigation method.
