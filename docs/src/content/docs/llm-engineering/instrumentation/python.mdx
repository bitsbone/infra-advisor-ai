The Datadog SDK shortens the path from supported Python frameworks to useful Agent Observability traces. InfraAdvisor relies on automatic integrations for library operations and adds explicit spans only where application-specific orchestration would otherwise be invisible.

**Source of truth:** `services/agent-api/src/`

## The boundary to understand

| Application behavior | How it becomes observable |
|---|---|
| LangChain or OpenAI model request | Automatically instrumented by `ddtrace` |
| LangGraph node execution | Automatically instrumented by the LangGraph integration |
| LangChain and MCP tool calls | Automatically instrumented as nested tool operations |
| Query workflow, routing, history load, source extraction | Explicit `LLMObs.workflow`, `LLMObs.agent`, or `LLMObs.task` spans |
| Product-specific domain, source count, or tool choice | Explicit annotations and bounded tags |

Automatic instrumentation describes supported libraries. Explicit instrumentation describes what those operations mean to InfraAdvisor.

## Bootstrap before instrumented libraries load

`ddtrace.auto` must be imported before LangChain, OpenAI, MCP, Redis, or other patched libraries:

```python
# services/agent-api/src/agent.py
import ddtrace.auto

from ddtrace.llmobs import LLMObs
from langchain_openai import AzureChatOpenAI
from langgraph.prebuilt import create_react_agent
```

The service enables Agent Observability during startup. A telemetry configuration failure is logged without taking the API down; observability should reveal application failure, not create it.

```python
def enable_llm_obs() -> None:
    LLMObs.enable(
        ml_app=os.environ.get("DD_LLMOBS_ML_APP", "infra-advisor-ai"),
        agentless_enabled=os.environ.get("DD_LLMOBS_AGENTLESS_ENABLED", "false").lower() == "true",
    )
```

## Model the orchestration once

The request workflow adds meaning around auto-instrumented children:

```python
with LLMObs.workflow("query-processing") as workflow:
    with LLMObs.task("load-history") as history_span:
        history = await load_history(session_id)
        LLMObs.annotate(span=history_span, tags={"history.turns": len(history)})

    with LLMObs.agent("router") as router_span:
        decision = await route(query, history)
        LLMObs.annotate(span=router_span, tags={"query.domain": decision.specialist})

    with LLMObs.agent(f"specialist-{decision.specialist}"):
        result = await react_agent.ainvoke(...)
```

Do not wrap an automatically instrumented model or tool call in another manual `LLMObs.llm()` or `LLMObs.tool()` span. That produces duplicate operations without adding meaning.

Annotate while the context manager is active. An annotation made after the `with` block targets a span that has already closed.

## Keep capture intentional

Automatic integrations can capture prompts, completions, model metadata, token counts, and tool inputs or outputs. That is useful for debugging only when the service's data policy allows it.

InfraAdvisor disables Agent Observability payload capture on the provider-adapter MCP deployment. That service retains ordinary APM timing and bounded metrics without copying external provider bodies into Agent Observability. Changing this boundary requires an explicit privacy review and updated tests.

<ObservationChecklist title="Verify the Python path">
  <ul>
    <li>The trace begins with `query-processing`, not an isolated LLM call.</li>
    <li>The router and selected specialist appear as agent operations.</li>
    <li>LangChain, OpenAI, and MCP operations nest beneath the explicit orchestration spans.</li>
    <li>Domain and source-count tags are present without secrets or raw provider payloads.</li>

## Diagnose the missing boundary

| Symptom | Likely boundary |
|---|---|
| No model spans | `ddtrace.auto` loaded too late or the integration/version is unsupported |
| Library spans exist but no workflow | Explicit orchestration wrapper did not run |
| Duplicate model or tool spans | An auto-instrumented call was also wrapped manually |
| Tags missing | Annotation ran after the span closed |
| Agentless export fails | `DD_API_KEY` or direct-ingestion configuration is missing |
